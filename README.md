# Ad Network Website

## Project Overview
A modern, professional, and highly responsive multi-page website for an Ad Network. The platform connects Advertisers, Publishers, Affiliates, and Traffic Sources. The design must convey trust, high performance, and modern tech aesthetics.

## Tech Stack
- **HTML5**: Semantic markup.
- **CSS3**: Modern CSS using Variables, Flexbox, and CSS Grid. No external frameworks (like Bootstrap) to keep it lightweight.
- **JavaScript**: Minimal vanilla JS only for the mobile hamburger menu and smooth scrolling.
